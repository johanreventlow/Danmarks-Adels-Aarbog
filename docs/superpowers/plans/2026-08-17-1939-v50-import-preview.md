# DAA 1939 v50 Import Preview Implementation Plan

> **For Codex:** Følg planen sekventielt med test-first RED → GREEN. Bevar
> `load_daa.R` urørt. Ingen databasekald før Task 6, og Task 6 må kun læse.

**Goal:** Forbind den afsluttede v50-reconciliation med 1939-konverteringen og
fremstil en hashbundet lokal preview samt en reelt skrivebeskyttet
Supabase-sammenligning af personer, relationer, provenance og forventede
databaseændringer.

**Architecture:** En ny Python-builder validerer de seks autoritative
artefakter, materialiserer et lukket preview-bundle og klassificerer alle
legacy claims fail closed. En separat R-komparator bruger et lille testbart
query-interface, starter `BEGIN READ ONLY`, verificerer read-only-status og
databaseidentitet og læser kun de berørte databaseflader. Den gamle loader og
produktionsdata ændres ikke.

**Tech Stack:** Python 3 + pytest, R + testthat + DBI/RPostgres/jsonlite,
PostgreSQL/Supabase read-only session.

**Design:**
`docs/superpowers/specs/2026-08-17-1939-v50-import-preview-design.md`
