# Billeder fra DAA 2018-20 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Importér portrætafsnittets ~156 billeder fra særudgaven af DAA 2018-20 som redaktionelle medier koblet til de afbildede personer, og lad forsiden bruge »har billede« som indhold.

**Architecture:** Python udtrækker billeder + billedtekster og laver varianter → `manifest.json`. Et R-script slår personerne op (læsende) og skriver en plan + en gennemgangsfil; med `--jeg-mener-det` uploader det til Storage og registrerer via de samme `red_*`-RPC'er som redaktørfladen, én transaktion pr. billede. Web og Edge-filen får en sjette kilde: personer med mindst ét gæste-synligt billede.

**Tech Stack:** Python 3.11 + Pillow + poppler (`pdfimages`/`pdftotext`), R (DBI/RPostgres, httr2, jsonlite, testthat), TypeScript/React/Vitest.

**Spec:** `docs/superpowers/specs/2026-11-24-billeder-2018-20-design.md`

## Global Constraints

- PDF: `Dansk Adels Aarbog - Reventlow - Særudgave.pdf` i repo-roden (worktree: `../../`), portrætafsnit s. 119-369.
- Udtræk og manifest ligger i `work_2018_saerudgave/billeder/` (gitignoreret — commit aldrig). `work_presens*/` røres aldrig.
- Ingen DDL, ingen RLS-ændringer, ingen nye anon-grants.
- Alle medier: `rettigheder_status = 'ukendt'`; `maa_publiceres = true` kun når **alle** afbildede er koblet (fail-closed).
- Identitet: `original_filnavn = 'daa-2018-20-s<side 4 cifre>-<billednr>.jpg'`, fx `daa-2018-20-s0150-1.jpg`.
- Kreditlinje (faktatype `kreditlinje`): `Gengivet fra Danmarks Adels Aarbog 2018-20, s. <side>`.
- Storage-sti: `redaktor/<sha[0:2]>/<sha>-<tier>.jpg` (samme som `web/src/data/mediaPaths.ts:buildShaStoragePaths`); `sha256` = hex af large-filens bytes.
- Varianter: thumb bredde `min(500, w)`, medium `min(1100, w)`, large = original; aldrig opskalering. Large er mediets egen sti; kun thumb/medium registreres med `red_registrer_media_variant`.
- Redaktør-uuid til rollegaten: `ba4ce28d-42a0-48af-a47c-773c26934236` (samme som `apply_d2_spouses_1939_v50.R`).
- Prod-skrivning kun med `--jeg-mener-det`, kørt i projektejerens shell. Standard = plan (læser, skriver intet).
- Commits: Conventional Commits på dansk, ingen Claude-attribution, ingen session-linje.

  - Henvisning: regex `\(([IVX]+|\d+)\s*,\s*(\d+)\)` → `[linje, int(nr)]`. Tekst deles ved `Gift med`: refs før = afbildede; første ref efter = `aegtefaelle_anker`. Ingen refs før + anker → `aegtefaelle`; `Fra venstre` → `gruppe`; >1 ref før → `flere`; ingen ref og intet anker → `uafklaret`.
